Toronto FAQ

Is the rent increase guideline the same in Toronto?

Yes — it's set provincially: 2.1% for 2026 and 1.9% for 2027. It applies to units first occupied before Nov 15, 2018; newer units are generally exempt (Form N2). Toronto's vacancy-rate rules for annual increases were eliminated from the 2018 changes — the guideline now applies city-wide.

Can I increase rent above the guideline?

Only in limited cases — an Above Guideline Increase (AGI) application to the LTB for eligible capital or security work, or if the unit is exempt. Otherwise the guideline is the cap.
